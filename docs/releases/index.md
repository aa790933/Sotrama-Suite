# Releases

Download installers and read release notes on the [GitHub Releases page](https://github.com/aa790933/Sotrama-Suite/releases). Use packages published by the project and check the release notes before upgrading a company database.

For development builds, review the GitHub Actions run and its attached artifacts. CI artifacts are intended for validation and may not have the same signing or support guarantees as a published release.
